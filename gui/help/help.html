mkpass-gui User Manual

Welcome to the official user manual for mkpass-gui, the graphical interface for the mkpass stateless password and passphrase generator.

1. The Concept Behind mkpass

Traditional password managers store your passwords in an encrypted vault. If that vault is lost, corrupted, or hacked, your access is compromised. mkpass takes a revolutionary stateless approach:

  • No Secret Vault Needed: Your passwords are not saved anywhere. Instead, they are deterministically generated on-demand whenever you need them.
  • One Master Password: You only remember a single Master Password.
  • Service-Based Generation: By combining your Master Password with a Service Name (e.g. github.com or my-email) and non-secret generation rules, mkpass derives the exact same strong password every single time.
  • Local Configuration History: Non-secret parameters (algorithm choice, password length, character sets) are stored locally in an SQLite database to provide convenient autocompletion and default settings.

2. Interface Overview

The main window consists of the following key components:

  • Master Password & Repeat Password: Enter your secret master password. The repeat field ensures you haven't made a typo.
  • Service: The name or URL of the service (e.g., google.com, work-vpn). Autocompletes known services from your database.
  • Algorithm Selector: Choose between cryptographic key derivation algorithms and passphrase modes:
    • Password (Argon2): Modern memory-hard password generation (Recommended).
    • Password (SHA512 HMAC): Iterative HMAC-SHA512 derivation.
    • Passphrase Diceware (Argon2): Word-based passphrase using the EFF Large wordlist.
    • Passphrase Wordnet Pattern (Argon2): Grammatically structured passphrases (e.g. Adjective + Noun + Verb).
  • Character Classes & Custom Characters: Toggle Lower-case, Upper-case, Digits, Symbols, or define Custom characters.
  • Length & Separator Controls: Adjust password length (characters) or passphrase length (words) and select word separators (Hyphen, Space, Slash).
  • Action Buttons:
    • Generate: Computes the password and displays it in a dialog.
    • Copy to Clipboard: Directly copies the generated password to your system clipboard without revealing it on screen.

3. Step-by-Step Instructions

3.1 Generating a Password for a New Service

  1. Launch mkpass-gui.
  2. Enter your Master Password in the Master Password and Repeat Password fields.
  3. Type the new service name in the Service field (e.g., amazon.com).
  4. Select your desired Algorithm (default is Password (Argon2)).
  5. Select the required character sets and length (e.g., 20 characters with digits and symbols).
  6. Click Generate Password or Copy to Clipboard.
  7. The service parameters are automatically saved in your local database for future use.

3.2 Regenerating a Password for an Existing Service

  1. Start typing the service name in the Service field.
  2. Select the service from the autocompletion dropdown. All previously saved non-secret parameters (algorithm, length, character sets) will automatically load.
  3. Enter your Master Password.
  4. Click Copy to Clipboard or Generate Password.

3.3 Managing the Saved Services Database

To inspect or clean up your saved service configurations:

  1. Click Database in the top menu bar and select Management.
  2. A dialog will open showing a list of all saved services along with their stored algorithm and length configurations.
  3. Use the search filter to locate specific entries.
  4. Select an entry and click Delete to remove it from local suggestions.

4. Security Features & Best Practices

Automatic Clipboard Wiping: Whenever you close mkpass-gui, the application automatically clears the system clipboard to prevent unauthorized applications from reading your copied password.
  • Memory Protection: Master passwords are kept in memory only for the duration of the generation computation.
  • No Network Transmission: mkpass-gui performs all calculations locally on your CPU. No internet connection is used or required.
  • Backup Your Parameters: Because generation is deterministic, as long as you remember your Master Password and know your service parameters, your passwords can never be lost.
