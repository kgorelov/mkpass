mkpass for Android - User Manual

Welcome to mkpass for Android, the mobile application for on-the-go stateless password and passphrase generation.

100% Offline & Mobile Secure: The Android app requires zero network permissions. Password derivation occurs natively on your device using compiled native C++ (JNI / Argon2). No passwords or service names ever leave your device.

1. About mkpass

mkpass is a stateless password generator. Instead of storing passwords in an encrypted vault or syncing secrets across servers, mkpass derives your passwords deterministically on-demand.

  • One Master Password: You only remember one master secret.
  • Service-Based Generation: Combine your Master Password with a Service Name (e.g., twitter.com or banking-app) to generate your password.
  • Local Suggestions: Non-secret service parameters (algorithm choice, length, character sets) are stored locally in your mobile device database for instant selection.

2. Features & Navigation

  • Master Password Input: Secure password field with toggleable visibility.
  • Service Autocomplete: Dropdown menu listing previously generated services on your device.
  • Algorithm Options:
    • Password (Argon2id): High-security memory-hard derivation (Default).
    • Password (SHA512 HMAC): SHA-512 derivation option.
    • Passphrase (Diceware EFF): Multi-word passphrases using EFF wordlists.
    • Passphrase (WordNet Pattern): Structured grammatical passphrases.
  • One-Tap Copy to Clipboard: Instantly copy the generated password for pasting into Android apps or browsers.
  • Database Management: View and remove old service profiles via the Android overflow menu.

3. How to Use

3.1 Generating a Password on Mobile

  1. Open the mkpass app on your Android device.
  2. Enter your Master Password.
  3. Type the Service Name (e.g. email.com).
  4. Select your configuration preferences (Length, Character Classes, or Passphrase options).
  5. Tap Generate Password.
  6. Tap Copy to Clipboard and switch to your target app to paste your password.

3.2 Managing Saved Service Preferences

  1. Tap the three dots (Menu) in the top-right corner of the action bar.
  2. Select Database Management.
  3. Browse saved services or search for a specific entry.
  4. Tap Delete next to any entry to remove it from your device history.

4. Security & Privacy

  • Zero Network Usage: The application operates entirely offline. No telemetry, analytics, or remote sync.
  • Protected Memory: Master password buffers are cleared when the app is minimized or closed.
  • Deterministic Reliability: Even if you switch phones or reinstall the app, entering the same Master Password and service options will generate the exact same password.
